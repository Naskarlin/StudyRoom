# StudyRoom
Android app for university students to find and book study rooms

## Project setup

| Setting | Value |
|---|---|
| Package name / application ID | `com.studyroom.app` |
| Language | Kotlin |
| UI | Jetpack Compose |
| Build scripts | Gradle Kotlin DSL with a version catalog (`gradle/libs.versions.toml`) |
| Minimum SDK | API 26 (Android 8.0) |

To open the project: clone this repository, then in Android Studio choose **File → Open** and select the project folder.
